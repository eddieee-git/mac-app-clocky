# 설치 안내

[← README로 돌아가기](../README.md) · [English](install.en.md)

## 요구 사항

- Apple 실리콘 Mac (M1 이상). Intel Mac은 지원하지 않아요.
- macOS 13 이상. 개발과 시험은 macOS 26에서 했어요.

## 설치하기

1. [Releases](https://github.com/eddieee-git/mac-app-clocky/releases)에서 `Clocky-<버전>.dmg`(0.2.1까지는 `Clocky.dmg`)를 내려받아요.
2. dmg를 열고 Clocky를 Applications 폴더로 끌어다 놓아요. dmg 창에서 바로 열면 dmg를 꺼낼 때 Clocky도 꺼지므로, 꼭 Applications 폴더에서 열어요.
3. dmg를 꺼내요.
4. Applications 폴더에서 Clocky를 실행해요.

실행해도 Dock에는 아이콘이 생기지 않아요. 화면 위쪽 메뉴바에 자명종 아이콘이 나타나고 시계 창이 뜨면 정상이에요.

릴리스에 적힌 SHA-256 값으로 내려받은 파일을 확인할 수 있어요.

```bash
shasum -a 256 ~/Downloads/Clocky*.dmg
```

## 처음 실행할 때 나오는 보안 경고

인터넷에서 받은 Clocky를 처음 열면 macOS가 실행을 막고 경고 창을 띄워요. 문구는 macOS 버전에 따라 조금씩 다르며, 대개 Apple이 악성 코드 여부를 확인할 수 없다는 내용이에요.

**왜 나오나요?** macOS는 Apple의 유료 개발자 프로그램으로 서명하고 공증받지 않은 앱을 기본으로 막아요. Clocky는 무료 프로젝트라 이 인증을 받지 않았어요. 앱에 문제가 발견되어 나오는 경고는 아니에요. 다만 Apple이 검사하지 않았다는 뜻은 맞아요. 믿을 수 있는 곳에서 받은 파일만 여세요. 코드는 이 저장소에 공개되어 있어서 직접 확인하고 [빌드](../README.md#직접-빌드하기)할 수도 있어요.

### 방법 1: 시스템 설정에서 허용

1. 경고 창에서 **완료**(버전에 따라 **확인**)를 눌러 닫아요. **휴지통으로 이동**은 누르지 마세요.
2. **시스템 설정 → 개인정보 보호 및 보안**을 열어요.
3. 아래로 내려 **보안** 항목의 Clocky 안내 옆에 있는 **그래도 열기**를 눌러요.
4. 확인 창이 나오면 다시 **그래도 열기**를 누르고, Mac 암호나 Touch ID로 승인해요.

처음 한 번만 하면 돼요. 새 버전을 설치하면 다시 해야 할 수 있어요. **그래도 열기** 버튼은 Clocky를 열어 본 뒤 약 1시간만 보여요.

### 방법 2: 터미널 명령

터미널을 쓴다면 이 명령 하나로 대신할 수 있어요. Clocky를 Applications 폴더로 옮긴 뒤에 실행하세요.

```bash
xattr -dr com.apple.quarantine /Applications/Clocky.app
```

"손상되었기 때문에 열 수 없어요"라는 문구가 나올 때도 이 명령으로 풀 수 있어요.

## 로그인할 때 자동으로 실행하기

**설정 → 일반 → 로그인 시 자동 실행**을 켜요. Clocky를 Applications 폴더에 둔 뒤에 켜세요. 알람이나 캘린더 알림을 쓴다면 켜 두기를 권해요. 앱이 꺼져 있으면 울리지 않아요.

## 캘린더 접근

**설정 → 캘린더 → Mac 캘린더 앱의 일정으로 알림**을 켜면 macOS가 캘린더 접근을 물어요. 허용해야 Mac 캘린더 앱의 일정을 읽어요. 거절했거나 나중에 바꾸려면 **시스템 설정 → 개인정보 보호 및 보안 → 캘린더**에서 Clocky를 켜요.

## 업데이트

Clocky는 하루에 한 번 GitHub에 새 버전이 있는지 확인해요. 새 버전이 있으면 메뉴바 메뉴에 **새 버전 0.x.x 설치…**가 나오고, **설정 → 일반 → 업데이트**에도 보여요. 바로 확인하려면 메뉴의 **업데이트 확인…**을 눌러요. 새 버전을 찾으면 Clocky를 쓰고 있지 않을 때 알아서 받아 바꿔 넣고 다시 켜요. 직접 확인하거나 메뉴의 **새 버전 0.x.x 설치…**를 눌러도 묻지 않고 바로 설치해요.

- 받은 파일이 GitHub에 올린 파일과 같은지(SHA-256), 만든 사람의 서명이 맞는지 확인한 뒤에만 설치해요. 서명이 없거나 맞지 않으면 설치하지 않아요.
- 앱이 직접 받은 파일이라 보안 경고와 **그래도 열기**가 다시 나오지 않아요.
- Applications 폴더처럼 쓸 수 있는 곳에 둔 Clocky만 스스로 업데이트할 수 있어요.
- Mac 캘린더 연동을 쓰고 있다면 업데이트 뒤 캘린더 접근을 다시 물을 수 있어요. 허용하면 돼요.

자동 확인은 설정 → 일반 → 업데이트의 **새 버전 자동으로 확인**으로 꺼요. 알아서 설치하는 것이 싫으면 **새 버전 자동으로 설치**를 꺼요(기본 켬). 끄면 새 버전이 나왔을 때 한 번 알려 줘요. 무언가 울리고 있거나 2분 안에 울릴 것이 있으면 다음 기회로 미뤄요.

**0.2.x에서 0.3으로**: 0.2.x는 앱 샌드박스 안에서 돌아 스스로 바꿔 넣지 못해요. 이번 한 번은 0.2.x가 받아 연 dmg에서 Clocky를 Applications 폴더로 끌어다 놓아 바꿔 주세요. 0.3을 처음 켜면 알람·타이머·설정·캘린더·내 소리 파일을 샌드박스 폴더에서 일반 위치로 옮기고, 받아 둔 dmg를 휴지통으로 옮길지 물어요. 그다음부터는 앱 안에서 바로 설치돼요.

**0.2.0이거나 직접 업데이트하려면**

1. 메뉴바 아이콘 → **Clocky 종료**로 앱을 꺼요.
2. 새 `Clocky-<버전>.dmg`를 열고 Applications 폴더로 끌어다 놓아 기존 앱을 대체해요.
3. 보안 경고가 다시 나오면 위의 방법으로 허용해요.

설정, 알람, 연결한 캘린더는 앱과 따로 저장되므로 그대로 남아요.

## 문제 해결

**보안 경고가 나오고 열리지 않아요**
위의 [처음 실행할 때 나오는 보안 경고](#처음-실행할-때-나오는-보안-경고)를 따르세요. **그래도 열기** 버튼은 Clocky를 열어 본 뒤 약 1시간만 보여요. 버튼이 없으면 Clocky를 한 번 더 열어 경고를 띄운 뒤 다시 가 보세요.

**"Clocky를 Applications 폴더로 옮겨 주세요"가 나와요**
dmg 창에서 바로 열었기 때문이에요. Clocky를 종료하고 Applications 폴더로 끌어 놓은 뒤 거기서 여세요. 그래야 dmg를 꺼내도 계속 돌고, 로그인 시 자동 실행도 돼요.

**메뉴바에 아이콘이 보이지 않아요**
메뉴바 아이콘이 많으면 노치나 다른 아이콘 뒤로 숨을 수 있어요. ⌃⌥C를 누르면 시계 창이 열려요. macOS 26부터는 **시스템 설정 → 메뉴 막대**에서 Clocky가 허용되어 있는지도 확인하세요.

**소리가 들리지 않아요**
- Mac이 음소거되어 있거나 소리가 블루투스 헤드폰 등 다른 장치로 나가고 있지 않은지 확인하세요.
- **설정 → 소리**에서 소리 크기와 ▶︎ 버튼으로 들어 보세요.
- 소리는 정한 시간(기본 1분)이 지나면 멈춰요. 창은 끌 때까지 깜빡여요.

**알람이 울리지 않았어요**
- 덮개를 닫았거나 Mac이 잠자는 동안에는 울리지 않아요. 깨어났을 때 지난 지 1시간이 안 된 알람은 바로 울려요(캘린더 알림은 15분).
- Clocky를 종료해 두었다면 울리지 않아요. 로그인 시 자동 실행을 켜 두면 좋아요.
- 알람의 **켜기** 스위치와 반복 요일을 확인하세요.

**캘린더 일정이 보이지 않아요**
- **설정 → 캘린더**에서 주소 옆에 오류가 나오는지 확인하세요. 주소를 찾을 수 없다고 나오면 비공개 주소를 다시 복사해 넣어요.
- Mac 캘린더 앱 연동은 **시스템 설정 → 개인정보 보호 및 보안 → 캘린더**에서 Clocky가 켜져 있어야 하고, Clocky 설정에서 그 캘린더를 골라야 해요.
- 앞으로 이틀 안의 일정만 보여요. 종일 일정과 거절한 일정은 기본으로 빠져요.
- iCal 주소는 15분마다 새로 받아요. 바로 보려면 **지금 새로 받기**를 누르세요.

**업데이트한 뒤 캘린더 접근을 다시 물어요**
Clocky는 개발자 인증서 없이 서명해서, 버전이 바뀌면 macOS가 다른 앱으로 볼 수 있어요. 다시 허용하면 돼요.

**업데이트 확인이 실패해요**
인터넷 연결을 확인하세요. 회사 네트워크가 GitHub를 막고 있을 수도 있어요. 그럴 때는 [릴리스 페이지](https://github.com/eddieee-git/mac-app-clocky/releases)에서 직접 받으면 돼요.

**전역 단축키가 동작하지 않아요**
다른 앱이 같은 키를 쓰면 등록되지 않아요. **설정 → 단축키**에서 표시를 확인하고 다른 키로 바꾸세요.

해결되지 않으면 [이슈](https://github.com/eddieee-git/mac-app-clocky/issues)로 알려 주세요. macOS 버전과 어떤 상황이었는지 적어 주시면 도움이 돼요.

## 삭제

1. 메뉴바 아이콘 → **Clocky 종료**로 앱을 꺼요.
2. Applications 폴더에서 Clocky를 휴지통으로 옮겨요.

설정, 알람, 연결한 캘린더, 내 소리 파일까지 지우려면 아래 명령을 실행해요. 마지막 폴더는 0.2.x가 쓰던 곳이에요(샌드박스에서 옮겨 올 때 지우지 않고 남겨 둬요). macOS가 다른 앱의 데이터에 접근해도 되는지 물으면 허용해요.

```bash
rm -rf ~/Library/Preferences/com.eddieee.Clocky.plist ~/Library/Application\ Support/Clocky ~/Library/Containers/com.eddieee.Clocky
```
