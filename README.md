탁상 넘김시계처럼 숫자판이 초마다 넘어가는 작은 창을 화면에 띄워 둬요. Dock에 아이콘이 생기지 않고 메뉴바에만 상주해요. 스티커 메모 앱 [Floaty](https://github.com/eddieee-git/mac-app-floaty)의 짝꿍 앱이에요.

## 특징

- **타이머 여러 개**: 타이머마다 이름과 시간을 정해 따로 돌려요. 시간 버튼(기본 1·3·5·10·25분)이나 직접 입력(`90`은 90분, `5:30`, `1:30:00`)으로 정하고, 일시정지·계속·초기화를 써요.
- **알람 여러 개**: 알람마다 이름, 시각, 반복(매일·평일·주말·한 번 또는 요일 지정), 켜기·끄기, 소리를 정해요. 울리기까지 남은 시간을 목록에서 바로 봐요.
- **캘린더 일정 알림**: 구글 캘린더 같은 일정이 시작하기 전(기본 5분 전)에 알람처럼 울려요. Mac 캘린더 앱을 거치거나(회사 구글 계정 포함) iCal 주소를 넣어 연결해요. [캘린더 연결](#캘린더-연결)을 보세요.
- **미리 알림과 울림**: 울리기 10초 전부터 창이 붉게 깜빡여요. 시각이 되면 창이 앞으로 나와 무엇이 울리는지 보여 주며 소리를 내요. 소리는 끌 때까지 되풀이하고(기본 1분까지), **다시 울림**을 누르면 정한 시간(기본 5분) 뒤에 한 번 더 울려요.
- **메뉴바**: 도는 타이머의 남은 시간을 보여 줘요. 도는 타이머가 없으면 1시간 안에 울릴 알람·일정까지 남은 시간을 종 아이콘과 함께 보여 줘요.
- **전체 목록**: 모든 타이머·알람·일정을 한 창에서 찾고, 여러 개를 골라 한꺼번에 켜고 끄고 지워요.
- **키보드**: 창 안의 단축키와, 다른 앱을 쓰는 중에도 동작하는 전역 단축키가 있어요. [단축키](#단축키)를 보세요.
- **손쉬운 사용**: VoiceOver가 숫자판을 "라면, 2분 46초 남음"처럼 한 문장으로 읽어요. "동작 줄이기"를 켜면 숫자판이 넘어가지 않고 붉은 배경도 깜빡이지 않아요.
- **앱 안 업데이트**: 새 버전이 나오면 알려 주고, 서명을 확인한 뒤 바꿔 넣고 다시 켜요.
- **한국어·영어**: 설정에서 바로 바꿔요. 처음에는 Mac의 언어를 따라요.

## 설치

Apple 실리콘 Mac(M1 이상), macOS 13 이상이 필요해요. Intel Mac은 지원하지 않아요.

1. [Releases](https://github.com/eddieee-git/mac-app-clocky/releases/latest)에서 `Clocky-x.y.z.dmg`를 내려받아 열어요.
2. **Clocky**를 **Applications** 폴더로 끌어다 놓아요.
3. Clocky를 열어요. Apple 개발자 서명이 없는 앱이라 처음 한 번은 열 수 없다는 경고가 나와요. **완료**를 누른 뒤:
   - **macOS 15(Sequoia) 이상**: 시스템 설정 → 개인정보 보호 및 보안을 맨 아래까지 내려서 Clocky 옆의 **그래도 열기**를 누르고, 한 번 더 **열기**를 눌러요.
   - **macOS 13·14**: 응용 프로그램 폴더에서 Clocky를 **오른쪽 클릭 → 열기**를 눌러요.

   터미널이 편하면 `xattr -dr com.apple.quarantine /Applications/Clocky.app`을 실행해도 돼요.
4. 메뉴바에 자명종 아이콘이 생기고 시계 창이 떠요.

Clocky는 하루에 한 번 새 버전이 있는지 확인하고, 있으면 Clocky를 쓰고 있지 않을 때 알아서 받아 바꿔 넣고 다시 켜요(무언가 울리는 중이면 미뤄요). 메뉴바 메뉴의 **업데이트 확인…**으로 직접 확인해도 묻지 않고 바로 설치해요. 알아서 설치하는 것이 싫으면 설정에서 **새 버전 자동으로 설치**를 꺼요. 자세한 내용과 [문제 해결](docs/install.md#문제-해결)은 [설치 안내](docs/install.md)에 있어요.

## 쓰는 방법

### 메뉴바

메뉴바의 자명종 아이콘을 누르면 메뉴가 나와요.

| 항목 | 내용 |
|---|---|
| Clocky 열기 | 시계 창을 띄워요 |
| 상태 줄 | 돌거나 멈춘 타이머, 켜 둔 알람, 하루 안의 📅 일정이 한 줄씩 나와요. 누르면 그 항목을 보여 줘요 |
| 전체 목록… (⌘L) | 모든 타이머·알람·일정을 한 창에서 살피고 고쳐요 |
| 설정… (⌘,) | 언어, 메뉴바 표시, 미리 깜빡임, 다시 울림, 소리, 캘린더, 단축키 등을 바꿔요 |

### 시계 창

창 위쪽에서 **타이머**와 **알람**을 골라요. 큰 숫자판 아래에 목록이 있고, 목록에서 고른 항목을 큰 판과 버튼으로 다뤄요. 맨 위 이름 칸은 고른 항목의 이름이에요. 목록 머리의 목록·톱니바퀴 버튼으로 전체 목록과 설정을 열어요.

- **타이머**: **＋ 타이머 추가**로 더해요. 시간을 정하고 **시작**을 눌러요. 목록 줄의 ▶︎·⏸ 버튼으로 고르지 않은 타이머도 바로 시작하거나 멈춰요.
- **알람**: **＋ 알람 추가**를 누르면 다음 정각에 매일 울리는 알람이 생겨요. 숫자판 아래에서 시각, 반복(**매일** 메뉴), **켜기**를 고쳐요. 알람 칸 아래에는 하루 안의 캘린더 일정이 나오고, 🔔 버튼으로 이번 알림만 꺼요.
- **지우기**: 목록 줄의 ✕로 지워요. 잘못 지웠으면 ⌘Z로 되살려요. 마지막 타이머 하나는 남아요.
- **울릴 때**: 창이 앞으로 나오지만 쓰던 앱의 키보드는 그대로 둬요. 창을 누르면 꺼지고, 어디서나 ⌃⌥X로도 꺼요. 시계 창을 쓰던 중이었다면 Esc도 돼요. **다시 울림** 버튼이나 S 키를 누르면 정한 시간 뒤에 다시 울려요(타이머는 그 시간짜리로 다시 돌아요).
- 이름을 비워 두면 "타이머 2", "알람 3"처럼 번호로 불러요.
- 창을 닫아도 타이머와 알람은 계속 돌고, 울리면 창이 다시 떠요. 창 크기는 바뀌지 않고, 옮겨 둔 자리를 기억해요.

### 전체 목록

<p align="center"><img src="docs/images/list.png" width="600" alt="Clocky 전체 목록 창"></p>

- 왼쪽에서 **전체·타이머·알람·캘린더**로 거르고, 이름으로 찾고, 알람을 다음 울림·시각·이름·추가한 순으로 정렬해요. **＋**로 새 타이머나 알람을 만들어요.
- 항목을 고르면 오른쪽에서 고쳐요. 타이머는 이름·시간·시작/일시정지, 알람은 이름·켜기·시각·반복·소리·다시 울림 취소, 일정은 이번 알림 켜고 끄기를 다뤄요.
- ⌘나 ⇧를 누른 채 여러 개를 골라 알람을 한꺼번에 켜거나 끄고, 복제하거나 지워요. 지운 것은 ⌘Z 한 번으로 모두 되살아나요.
- 줄을 두 번 누르면 시계 창의 큰 숫자판에 보여 줘요. 울리는 동안에는 창 위의 붉은 막대에서 끄거나 다시 울림을 골라요.

### 캘린더 연결

<p align="center"><img src="docs/images/calendar.png" width="560" alt="Clocky 설정의 캘린더 탭"></p>

두 가지 방법이 있고, 함께 써도 돼요. **설정 → 캘린더**에서 연결해요.

#### Mac 캘린더 앱 경유 (회사 구글 계정 등)

1. **시스템 설정 → 인터넷 계정**에서 구글 계정을 추가하고 **캘린더**를 켜요. Apple 계정은 필요 없어요. Mac의 캘린더 앱에 일정이 보이면 돼요.
2. Clocky에서 **Mac 캘린더 앱의 일정으로 알림**을 켜요. macOS가 캘린더 접근을 물으면 허용해요.
3. 알림을 받을 캘린더만 체크해요. 처음에는 모두 켜져 있어요.

캘린더 앱이 새 일정을 받으면 Clocky도 바로 반영해요. Clocky는 개발자 인증서 없이 서명하므로, 새 버전으로 바꾸면 캘린더 접근을 다시 물을 수 있어요.

#### iCal 주소 (구글 캘린더 개인 계정 등)

1. 웹에서 [구글 캘린더](https://calendar.google.com)를 열고 **설정 → 왼쪽에서 캘린더 고르기 → 캘린더 통합**으로 가요.
2. **iCal 형식의 비공개 주소**를 복사해요.
3. Clocky에서 **캘린더 추가…**를 누르면 복사한 주소가 미리 채워져요. **추가**를 눌러요.

15분마다, 그리고 Mac이 깨어날 때 새로 받아요. 바로 받으려면 **지금 새로 받기**를 눌러요. 비공개 주소를 아는 사람은 일정을 볼 수 있으니 다른 곳에 올리지 마세요. 새어 나갔다면 구글 캘린더에서 재설정하세요.

> [!NOTE]
> 회사·학교(Google Workspace) 계정은 관리자가 막아 두어 **비공개 주소**가 보이지 않을 수 있어요. 그럴 때는 Mac 캘린더 앱 경유를 쓰세요. 이미 공개해 둔 캘린더라면 **iCal 형식의 공개 주소**도 쓸 수 있어요. 다만 공개 주소는 이메일만 알면 누구나 볼 수 있고, 공개 범위가 "한가함/바쁨만"이면 일정 이름 없이 울려요.

#### 두 방법 공통

- 알림 시점은 일정 시작할 때, 1·5·10·15·30분 전 중에서 골라요.
- 종일 일정과 내가 거절한 일정은 기본으로 울리지 않아요. 설정에서 바꿔요.
- Clocky가 켜져 있고 Mac이 잠들어 있지 않을 때 울려요. 잠든 사이에 지난 알림은 15분 안이면 깨어나서 울려요. 이미 울린 일정은 앱을 다시 켜도 또 울리지 않아요.
- iCal 주소는 Clocky가 직접 해석해요. 반복 일정, 빠진 날짜, 한 번만 옮긴 일정, 시간대를 다루지만, 아주 드문 반복 규칙(예: "매달 마지막 평일")은 첫 시각만 알려요.

### 알아 두면 좋은 동작

- 타이머와 알람은 앱을 다시 켜도 유지되고, 돌던 타이머는 이어서 돌아요.
- 타이머가 도는 동안과 알람·일정이 10분 안에 울릴 때는 Mac이 저절로 잠들지 않게 해요(화면은 꺼질 수 있어요). 덮개를 닫으면 잠들어서 울리지 않아요. 설정 → 타이머·알람에서 끌 수 있어요.
- 앱이 꺼진 동안 끝난 타이머나 지난 알람은 1시간 안에 다시 켜면 켜자마자 울려요.
- Mac이 잠든 동안 끝난 타이머는 깨어나면 바로 울려요. 알람은 1시간 안에 지난 것만 울려요.
- 그보다 늦어 울리지 못한 알람·타이머·일정은 시계 창과 메뉴바 메뉴에 **놓친 알림**으로 보여 줘요. **확인**을 누르면 사라져요.
- 곧 울릴 것이 있는데 Mac 소리가 꺼져 있으면(음소거, 소리 크기 0) 시계 창과 메뉴바 메뉴에서 알려 줘요.
- 시간대를 바꾸거나 시계를 고치면 알람은 새 시각에 맞춰 다시 잡히고, 도는 타이머와 다시 울림은 실제로 흐른 시간대로 남아요.
- 모니터를 빼서 창이 화면 밖으로 나가면 남은 화면으로 옮겨져요.

## 단축키

시계 창이 앞에 있을 때 써요. 이름 칸을 고치는 중에는 스페이스·화살표가 글자 입력으로 가요. Esc로 편집을 끝내면 다시 단축키로 쓰여요.

| 키 | 동작 |
|---|---|
| 스페이스 | 고른 타이머 시작·일시정지, 고른 알람 켜기·끄기 |
| Return | 고른 타이머 시작·일시정지 |
| ↑ ↓ | 목록에서 위·아래 항목 고르기 |
| ⌘N | 타이머 또는 알람 추가 |
| ⌘⌫ | 고른 항목 지우기 |
| ⌘Z, ⇧⌘Z | 지운 항목 되살리기, 다시 지우기 |
| ⌘1, ⌘2 | 타이머, 알람 |
| Esc | 울림 끄기, 이름 편집 끝내기 |
| S | 울리는 동안 다시 울림 |
| ⌘L, ⌘, | 전체 목록, 설정 |

다른 앱을 쓰는 중에도 동작하는 전역 단축키예요. 설정의 **단축키** 탭에서 바꾸거나 지워요. 손쉬운 사용 권한이 필요 없어요.

| 기본 키 | 동작 |
|---|---|
| ⌃⌥C | 시계 창 보이기/숨기기 |
| ⌃⌥T | 고른 타이머 시작/일시정지 |
| ⌃⌥X | 울림 끄기 |
| (없음) | 전체 목록 열기 |

## 설정

| 탭 | 항목 |
|---|---|
| 일반 | 언어, 로그인 시 자동 실행, 삭제하기 전에 확인, 메뉴바에 타이머·알람 남은 시간 표시, 새 버전 자동으로 확인(기본 켬)·자동으로 설치(기본 켬) |
| 타이머·알람 | 미리 깜빡이기(끄기, 5·10·30·60초 전), 다시 울림 간격(1~30분), 소리를 되풀이하는 시간(10초~5분), 곧 울릴 것이 있으면 Mac이 잠들지 않게(기본 켬), 타이머 버튼(분, 6개까지) |
| 소리 | 알람 소리(고르면 들려줌), 내 소리 파일 추가·지우기, 소리 크기 |
| 캘린더 | Mac 캘린더 앱 연동과 캘린더 고르기, iCal 주소 추가·켜기·빼기, 알림 시점, 종일·거절한 일정 포함 여부 |
| 단축키 | 전역 단축키 바꾸기, 창 안 단축키 안내 |
| 정보 | 버전, GitHub·변경 기록·문제 알리기 링크, 다른 앱 |

## 자주 묻는 질문

**어떤 정보를 보내나요?**

- 설정, 알람, 일정은 이 Mac에만 저장되고 다른 곳으로 보내지 않아요. 외부 라이브러리는 없어요.
- 인터넷은 설정에 넣은 iCal 주소에서 일정을 받아 올 때와, 하루에 한 번 GitHub에 새 버전이 있는지 확인할 때만 써요. iCal 주소는 https만 받고, 화면에는 비밀 부분을 가려서 보여 줘요. 업데이트를 확인할 때 GitHub는 여느 웹 요청처럼 IP 주소와 Clocky 버전을 봐요. 업데이트 확인은 설정에서 끌 수 있어요.
- iCal 비밀 주소는 Clocky의 설정 파일(`~/Library/Preferences/com.eddieee.Clocky.plist`)에 저장돼요. 이 Mac의 사용자 계정 안에 있는 보통 설정 파일이라 같은 계정에서 도는 다른 앱도 읽을 수 있고, Time Machine 같은 백업에도 함께 들어가요.
- 새 버전은 만든 사람의 서명(Ed25519)이 맞을 때만 받아서 설치해요. GitHub 계정이 털려 파일이 바뀌어도 서명이 맞지 않으면 받지 않아요.
- 캘린더 접근은 Mac 캘린더 연동을 켰을 때만 묻고, 일정의 제목·시각·참석 여부만 읽어요.
- 강화 런타임을 켜서 서명해요. 앱 안에서 스스로 업데이트하도록 0.3부터는 앱 샌드박스를 쓰지 않아요(다른 eddieee 앱과 같아요). 설정은 `~/Library/Preferences/com.eddieee.Clocky.plist`, 캘린더 캐시와 내 소리 파일은 `~/Library/Application Support/Clocky`에 저장돼요.

**보안 경고, 소리, 캘린더 문제는 어디를 보나요?**
[설치 안내의 문제 해결](docs/install.md#문제-해결)에 모아 뒀어요. 보안 문제를 발견하면 [SECURITY.md](SECURITY.md)를 따라 비공개로 알려 주세요.

## 지우기

1. 메뉴바 Clocky 아이콘 → **Clocky 종료**
2. 응용 프로그램 폴더에서 Clocky를 휴지통으로
3. (선택) 설정, 알람, 연결한 캘린더, 내 소리 파일까지 지우려면 `rm -rf ~/Library/Preferences/com.eddieee.Clocky.plist ~/Library/Application\ Support/Clocky ~/Library/Containers/com.eddieee.Clocky` (마지막은 0.2.x가 쓰던 폴더예요)

## 직접 빌드하기

Xcode 없이 Command Line Tools만 있으면 돼요.

```bash
scripts/build-app.sh
```

`build/Clocky.app`과 `build/Clocky-<버전>.dmg`가 만들어져요. 아이콘을 다시 그리려면 `swift scripts/make-icon.swift`를 실행해요.

시험은 Command Line Tools에 든 Swift Testing으로 돌려요.

```bash
scripts/test.sh
```

창을 실제로 띄워 보는 시험은 `scripts/gui-test.sh`로 돌려요. `Tests/GUI`의 시나리오마다 따로 빌드해 실행해요. `calendar` 시나리오는 이 Mac 안에 작은 웹 서버를 띄워 받아 오기부터 울리기까지 보고, `update` 시나리오는 GitHub 릴리스처럼 꾸민 서버로 새 버전 찾기와 받기를 보고, `readme-shots` 시나리오는 문서 이미지를 `build/shots`에 찍어요. 화면이 잠겨 있으면 클릭과 키가 창에 닿지 않으므로, 그런 시나리오는 건너뛰고 끝에 알려 줘요.

```bash
scripts/gui-test.sh
```

바뀐 점은 [CHANGELOG](CHANGELOG.md)에 있어요.
